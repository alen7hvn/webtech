## 2. Selectors lezen

Welke elementen raakt elke selector? Eén zin per selector.

- a. `header nav ul li a`: alle a's
- b. `article > p`: alle p's binnen het element article
- c. `.uren li:nth-child(3)`: het derde kind in de klasse uren
- d. `h2 ~ p`: elke p element na een h2 element
- e. `.rassen li:first-child`: eerste kind element binnen de klasse rassen
